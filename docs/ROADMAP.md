# 拍キープ・ドリル（English Beat Keeper）ロードマップ

最終更新: 2026-10-12

このファイルは、開発セッションをまたいで方針と現状を引き継ぐためのメモです。
新しいセッションを始めたら、まずここを読んでください。

---

## 1. コンセプト

- 英語は「強い音（オモテ）＝1拍」、日本語は「1音（モーラ）＝1拍」。
- 各セットは同じ強い単語（拍の数）のまま、レベル1→5で弱い音が増えていく。テンポは変えずに言い切れたら合格。
- 練習の流れ: 遅めのテンポで口を慣らす → AI声が自然に聞こえるテンポに上げて、お手本に合わせる。
- 「楽しい・グルーヴを感じる」ことが続けられる理由。ここは崩さない。

## 2. 現在の実装（2026-10 時点）

### アプリ（`index.html` 1ファイル）
- 開発中の確認用に、claude.ai のアーティファクトとして公開している（非公開）。
  URL: https://claude.ai/artifact/XfY3n7zmKj467ftnvWd3si
- 場面: 基本（無料予定）32セット / ビジネス / 日常会話 / 表現 / 旅行（有料予定）。
- 流し方（ウラの詰め方）: 自然（均等）/ **ネイティブ（初期値。強い音節を弱い音節の1.7倍の長さに）** / 厳密。
- テンポ: BPM 80〜160。練習・ふつう・自然のプリセットは**セットごとに決め打ち**（後述）。
- 繰り返し: 通し → 1行ループ → セットループ → カテゴリループ（同じ場面・拍数の全セット）。
- 各行のくり返しは1〜5回。
- 再生中にBPMが変わったら、新しいBPMで4カウントを入れてから次の行へ。
- 開発者モード（設定 → その他）: 選んだ場面の全拍数・全セット・全行を順番に再生してログを取る（短縮形も可、ループ可）。
- 遊び機能（優先度低）: 303 / DX7 / ギターの音節音。

### AI声（拍に合わせたお手本音声）
- 生成: `tools/make_voice.py`（Kokoro-82M、Apache-2.0、商用可）。
  - 声: 女性 `bf_emma`（標準）/ 男性 `bm_george`。どちらもUK英語。
  - 録音を後から伸び縮みさせるのではなく、**Kokoroの音素の長さを書き換えてから合成**している。
    - 強い音節の頭（子音）を拍に合わせる。
    - 余った時間は、まず強い母音（最大1.6倍）→伸ばせる子音（1.2倍）で埋める。拍全体の伸びは1.3倍まで。
    - さらに余った分は、最大0.15秒の間（語尾を5%まで減衰）と、母音の追加の伸ばし（チャンツ寄り）で埋める。
    - 弱い音節は −12dB、20%短く、少し低く。強い音節は音程を10%上げる。
    - 弱く読む機能語は、IPA表の弱形（ðə, həv, bɪn など）を指定して読ませる。
  - BPM 80〜160 を10刻みで作成。アプリは一番近いBPMを選んで、全体を数%だけ均等に伸び縮みさせる（WSOLA）。
  - 1拍に音が入りきらないBPMは作らない（その場合アプリは音節の音で再生し、範囲を表示する）。
- データ: `voice/manifest.json` と `voice/<声>/s<セット番号>.mp3`（1セット・1声で1ファイル、40kbps）。
  - アプリは読み込み時にMP3デコーダーの頭の遅れ（約46ms）を測って補正する。
  - `manifest.range[<set>:<line>:<full|short>] = [自然に聞こえる最遅BPM, 最速BPM, 素読みテンポ]`（全540行ぶんある）。
- 収録済み: **基本32セット × 男女**。残りのカテゴリは未生成。

### テンポのプリセット（セットごと）
- ふつう = そのセットの行ができるだけ多く「自然に聞こえる範囲」に入るBPMのうち、最も遅いもの。
- 自然 = 各行の素読みテンポの中央値（ふつう＋10以上）。
- 練習 = ふつう × 0.8（最低80）。範囲外なので、AI声モードでは注意書きを出す。
- 範囲は常に通常形（full）から計算する（短縮形を切り替えてもテンポが変わらないように）。

### コマンド
```bash
# 全行の自然なテンポ範囲を計算（基準は bf_emma）
python tools/make_voice.py index.html voice --ranges
# セットの音声を生成（例: 男性の声でセット0と1）
python tools/make_voice.py index.html voice --voice bm_george 0 1
```
- 必要なもの: Python venv に torch（CPU版）, kokoro, soundfile, lameenc。
- 必要なネットワーク許可: huggingface.co, *.huggingface.co, *.hf.co, download.pytorch.org。
- 1セット・1声の生成は数分。男女を並行で回せる（manifestの保存は声ごとにマージされる）。
- 注意: アーティファクトの上限は、1つの版で511ファイル・256MB、1回の公開で64MB。
  音声を増やすときは公開を何回かに分ける。

## 3. 決まっている方針

- 例文の基準: 実際に口にする文 / 意味のある the・her は残す / 文法はよく使う順 / 内容語は高頻度語 / イギリス英語の綴り。
- 旅行セットは「丁寧さを足す」でレベルを上げる（強い音は固定）。
- AI声は 100 BPM 前後以上が本命。行ごとの自然な範囲から外れたら注意書きを出す。
- 日本語訳の表示は保留。

## 5. 残っている課題・メモ

- 「言い切った行」の記録は「セット番号＋レベル」で保存している。例文を書き換えたレベルも完了扱いのまま残る。
- 1つのファイル（約2,000行）が限界に近い。公開前に Vite + TypeScript へ分割したい。
- 例文の拍の頭そろえ（全拍を同じ長さにする）は英語の理想化。強い音が隣り合う箇所は実際には詰まる。
- 「TR-808」などはローランドの商標なので、宣伝での表記に注意。
